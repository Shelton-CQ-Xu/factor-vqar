# Factor Vector Quantile Autoregression for High-Dimensional Time Series

Manuscript in preparation.

Nonparametric vector quantile autoregression describes the conditional distribution of a multivariate
time series through center-outward quantiles computed by optimal transport. It becomes infeasible when
the dimension of the series is large. This project carries out the quantile autoregression in a
low-dimensional factor space and lifts the resulting quantile regions back to the original series, which
gives predictive regions in the observation space. Coverage is studied in theory and in simulations.
